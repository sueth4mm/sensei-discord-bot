# 🥋 SenSei 4M DEV 

> Discord Voice Ranking & Management Bot built with Python.

SenSei is a modular Discord bot designed to manage communities through voice activity tracking, administrative tools, server logging, and automation features.

---

## ✨ Features

### 📊 Voice Ranking
- Automatic voice time tracking
- AFK channel exclusion
- Weekly ranking reset
- Individual member statistics
- Complete server ranking

### 🛠️ Administration
- Administrative slash commands
- Console-only commands
- Permission system
- Password-protected reset system

### 📋 Server Logs
- Message deletion logs
- Voice channel activity logs
- Member join/leave logs
- Nickname change logs
- Role update logs
- Channel management logs

### 👋 Community Management
- Welcome messages
- Goodbye messages
- Automatic server statistics panel
- Custom embeds

### 💾 Data
- SQLite database
- Automatic backups
- JSON configuration
- Modular architecture

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sueth4mm/sensei-discord-bot.git
```

Open the project

```bash
cd sensei-discord-bot
```

Install dependencies

```bash
pip install -r requirements.txt
```

Rename

```text
config.example.json
```

to

```text
config.json
```

Fill in your Discord credentials and run

```bash
python main.py
```
